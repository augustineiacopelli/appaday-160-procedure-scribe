Settings

  

    
The copy and paste path needs no key. Add an Anthropic API key only if you want to send the prompt directly. The key is held in page memory only, is never stored, and is wiped by Clear or by closing the tab.

    

    

    
  




  
About

  

    
The raw transcript path is fully local. Your file is read in place by an audio engine and a Whisper speech model that run inside this page. The only downloads are the app's own code and model files, served from this site and kept in the browser's model cache. Transcripts, prompts, outputs, and any API key live in page memory only and disappear on Clear or when the tab closes.

    
Anything you paste into Claude is governed by your Claude account settings and your employer's policy. Confirm your employer's AI data policy before pasting sensitive material.
